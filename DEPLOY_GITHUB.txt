ARAB TECHNOLOGY — V7 STATIC HTML/CSS/JS

1. Extract ZIP.
2. Copy ALL files and folders to the ROOT of your GitHub repository.
3. Run these commands in VS Code terminal, inside the repo:

   git add -A
   git commit -m "Arab Technology V7 About Policies Calibration"
   git push origin main

4. Confirm Settings > Pages > main > /(root).
5. Check /about.html, /policies.html, /resources.html, /calibration.html.
6. Before launch, verify calibration publication permission, certificate status,
   legal translations/effective date, and the two unpublished new products.
