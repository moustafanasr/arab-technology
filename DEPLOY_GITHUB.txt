Arab Technology — upload commands

1. Unzip the supplied website and place all files in the root of your local arab-technology repository.
2. Open VS Code terminal inside the repository folder.

Git commands:
    git add -A
    git commit -m "Finalize Arab Technology website V8 and product pages"
    git push origin main

If it is the first upload to a new empty repository, run instead:
    git init
    git branch -M main
    git remote add origin https://github.com/moustafanasr/arab-technology.git
    git add -A
    git commit -m "Arab Technology website V8"
    git push -u origin main

GitHub Pages:
    Settings > Pages > Deploy from a branch > main > /(root) > Save

Preview:
    https://moustafanasr.github.io/arab-technology/

Note: Do not force-push over another person's changes. Check git status first.
